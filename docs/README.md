# Note App Documentation

## Overview

Note App is an elegant note-taking application built with **Next.js 16**, **React 19**, and **Tailwind CSS v4**. It provides a fast, clean interface for capturing, editing, and organizing your thoughts.

### Key Features

- 📝 Add new notes
- ✏️ Edit existing notes in-place
- 🗑️ Delete unwanted notes
- 🔐 User authentication (login/logout)
- 🌙 Dark theme by default
- ⚡ Client-side state management with React hooks
- ♿ Full accessibility support

### Tech Stack

| Technology | Version | Purpose |
|---|---|---|
| Next.js | 16.2.11 | Web framework |
| React | 19.2.4 | UI library |
| Tailwind CSS | 4.3.3 | Styling system |
| Prisma | 7.9.1 | ORM / Database abstraction |
| SQLite (via better-sqlite3) | 13.0.1 | Database engine |

### Quick Start

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to see the app running.
